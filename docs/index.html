Projeto em destaque

PROJETO PESSOAL • FULL STACK

Controle de Produção

Sistema web desenvolvido a partir da minha experiência profissional em planejamento e controle de produção. A aplicação centraliza o gerenciamento de clientes, pedidos, peças e ordens de serviço.

O problema

No ambiente de produção, informações importantes podem ficar espalhadas entre planilhas, documentos e controles manuais. O projeto busca organizar esses dados em uma aplicação única, facilitando o acompanhamento do fluxo produtivo.

Principais funcionalidades

  • Cadastro e gerenciamento de clientes
  • Controle de pedidos e peças
  • Gerenciamento de ordens de serviço
  • Integração entre frontend, API e banco de dados

Tecnologias

  • React
  • TypeScript
  • Node.js
  • Express
  • Prisma
  • PostgreSQL
  • 🔐 JWT
